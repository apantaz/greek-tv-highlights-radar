# Future Streamlit analytics app

The Streamlit application is planned but not implemented. It will consume tested dbt
marts rather than reading raw ingestion tables or calling external APIs directly.

Planned views include:

- daily highlights with transparent ranking factors;
- archive search and channel/date filters;
- programme details backed by confidently resolved metadata;
- matched and unresolved enrichment coverage; and
- ingestion and enrichment pipeline status.

Implementation follows the dbt enrichment intermediate and mart deliveries in
Milestone 5. See the
[project roadmap](../docs/roadmap.md) for the current sequence.
